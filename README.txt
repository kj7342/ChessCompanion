CHESS COMPANION — iPhone web app

Features:
- Legal chess moves and a computer opponent
- Easy, Medium, Hard, and Expert difficulty
- Suggested move hints
- Undo (takes back your move and the computer's reply when applicable)
- Choose to play as White or Black
- Move history

Publish with GitHub Pages:
1. Open repository Settings -> Pages.
2. Under Build and deployment, select Deploy from a branch.
3. Choose branch main and folder /(root), then Save.
4. Wait for GitHub Pages to publish, then open the HTTPS URL in Safari.
5. Tap Share -> Add to Home Screen.

The app loads chess.js 1.4.0 from jsDelivr, so internet is needed on first load. The computer opponent is a built-in minimax search, not Stockfish.
